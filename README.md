Deletes `ain't` from the dictionary — the word that famously isn't a word. "Ain't ain't a word" is the most famous dictionary joke in English: the word's whole identity is being the word that isn't a word, so erasing it makes the pedants right at last. The entry is exactly one word, `ain't`, and nothing else.

## Run it

```sh
node main.ts
```

The program writes the entry text to `/output/entry.txt` (or `./output/entry.txt` when run locally without a writable `/output`).
